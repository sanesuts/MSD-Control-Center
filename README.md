# MSD-Control-Center

Open-source control center for the Mars Gaming MSD-PRO, with a focus on Linux compatibility.

## Project goals

The goal is to develop a native Linux application capable of controlling and configuring the Mars Gaming MSD-PRO.

Planned features:

- USB device detection and communication.
- LCD screen image management.
- Animation playback.
- Button and rotary encoder input handling.
- Configuration profiles.
- Graphical user interface.
- Linux integration.

## Technology

- C#
- .NET
- Linux
- USB Communication

## Project status

<escape>🚧</escape> **Early development — not yet ready for everyday use.**

The USB protocol is being independently reverse-engineered to implement compatible functionality.

Features and documentation will be added as development progresses.
